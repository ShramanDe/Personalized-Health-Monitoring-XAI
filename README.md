# Personalized Health Monitoring using Explainable AI

## Overview
This project implements PersonalCareNet, a personalized health monitoring framework using machine learning and explainable AI techniques on the MIMIC-III dataset.

## Features
- Patient demographic analysis
- Vital sign extraction
- Laboratory test processing
- Health outcome prediction
- Explainable AI using SHAP/LIME
- Data visualization

## Dataset
MIMIC-III Clinical Database

## Technologies
- Python
- Pandas
- NumPy
- Scikit-Learn
- TensorFlow/Keras
- SHAP
- Matplotlib
